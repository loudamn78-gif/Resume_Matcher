# 📄 مطابق السير الذاتية بالذكاء الاصطناعي (Resume Matcher)

تطبيق ذكي يساعد الباحثين عن عمل ومسؤولي التوظيف على تحليل ومطابقة السيرة الذاتية مع المتطلبات الوظيفية بنسبة دقيقة.

---

## 🌟 المميزات الرئيسية
* **تحليل السيرة الذاتية:** استخراج المهارات والخبرات الأساسية من الملفات.
* **مطابقة الوظائف:** مقارنة محتوى السيرة الذاتية مع الوصف الوظيفي المحدد.
* **تقارير وتوصيات:** تقديم نسبة المطابقة واقتراح الكلمات المفتاحية لمساعدة المتقدم على تحسين سيرته.

---

## 🛠️ التقنيات المستخدمة
* **Python** 🐍
* **Streamlit** 🎈
